# Result files

Files in this directory are computational outputs. Non-timing archived outputs are checked by `scripts/audit_reported_numbers.py`. The files `chain_scaling.txt` and `clique_stress.txt` contain timings from the machine on which that package run was executed and can differ from the manuscript because wall-clock time is hardware dependent. The exact timing values printed in the manuscript are preserved separately in `reference/`.

Raw-data pipeline files (`pipeline_full_bn_run.*`, `pipeline_sensitivity_run.*`, and `pipeline_common_relation_sensitivity.csv`) appear here only after the public Year-1 and Year-7 xlsx files are supplied and the corresponding scripts are run.
