\section*{Data and code availability}
The benchmark networks (Asia, Insurance, and ALARM) are publicly available,
and their structures are included in the accompanying reproducibility archive.
The pipeline-inspection data are publicly available from Mendeley Data DOI
\texttt{10.17632/c2h2jf5c54.1}; the archive contains the code and fixed baseline
graph used for the pipeline analyses, while the public spreadsheets are not
redistributed. The archive also contains the SMART-DS external structural-validation
outputs and a provenance record that pins the public source topology to a specific
Git commit. The accompanying code includes pinned software versions, random seeds,
unit tests, machine-readable outputs, and scripts for the verification, scaling,
benchmark, information-protection, pipeline, and external structural-validation
analyses. Wall-clock timings are hardware dependent and are not expected to match
exactly across machines.
